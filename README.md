# MeetingCopilot

macOS 原生小工具：在会议、面试、导师交流中，**实时捕获系统音频（对方）和麦克风（你）→ 本地转写文字 → 连同屏幕截图发给 AI**，流式给出可直接说出口的回答、要点或会后总结。

适用于腾讯会议、飞书、Zoom、Chrome 网页会议等任何从电脑播放声音的场景（耳机也可以）。

## 版本更新

### v0.1.4（2026-10-23）
- 新增**云端语音识别（可选）**：阿里云百炼 Paraformer 实时识别；默认仍为本地 Whisper，云端模式需 API Key、音频会发送到阿里云并按量计费。
- 新增**本机历史记录**：左侧历史栏可打开、右键重命名、删除、清空；「新话题」保存当前对话并开始新记录；历史保存可在设置关闭。
- 历史记录只保存定稿转写和回答文本，不保存音频/截图。

## 特性
- **实时转写**：本地 Whisper（WhisperKit），自动识别中文 / 英文 / 中英混杂，音频不出本机。
- **云端识别（可选）**：可切换到阿里云百炼 Paraformer 实时识别；云端模式会把音频发送到阿里云并按量计费，默认仍是本地 Whisper。
- **多种 AI**：OpenAI 兼容接口（OpenAI、DeepSeek、OpenRouter、本机 Ollama 等）和 Anthropic Claude。
- **自定义提示词**：全局系统提示词 + 任意数量的预设（内置：实时回答、速记要点、追问建议、屏幕解读、会后总结）。
- **屏幕解读**：提问时可附带当前屏幕截图，答案旁显示本次使用的截图；可选择截取哪块屏幕。
- **整场对话上下文**：每次提问都带上整场双方对话，并单独标出对方刚说完的“当前这一轮”；记录只在末尾追加，利用服务端前缀缓存保持响应速度。详见 [MANUAL.md](MANUAL.md) 第 6 节。
- **连续追问**：每次提问会带上最近 2 次问答（只带提问摘要和回答，不重复发转写），追问时模型能前后一致；设置里可调（0 = 不带），话题切换时点底部「新话题」。
- **自动回答**：持续判断对方这一轮话是否说完，说完立即触发；你开口回应时不触发，对方只是寒暄时模型会自动略过。
- **补充提问**：底部输入框支持多行，回车换行，⌘↩ 发送完整内容。
- **界面适配**：窗口可缩到 720×500；工具栏按宽度自动切换完整/紧凑布局；设置页、提示词编辑区和输入框在缩放时仍可完整显示或滚动。
- **历史记录**：对话自动保存在本机；左侧历史栏可打开、右键重命名、删除、清空；点「新话题」保存当前对话并开始新记录。
- **只读且安全**：见下文「安全设计」。

## 系统要求
macOS 14 及以上；Apple 芯片体验最佳。从源码构建需要 Xcode 或 Swift 工具链。

## 安装

### 方式一：下载 DMG（推荐）
1. 到 [Releases](../../releases) 下载 `MeetingCopilot-x.y.z.dmg`，打开后把 MeetingCopilot 拖到「应用程序」。
2. 本应用使用自签名证书、没有经过 Apple 公证，首次打开会被 macOS 拦截。处理方法二选一：
   - 在「应用程序」里**右键 MeetingCopilot › 打开 › 打开**；
   - 或在终端执行：`xattr -dr com.apple.quarantine /Applications/MeetingCopilot.app`
3. 想自行确认代码再使用，请用方式二从源码构建。

### 方式二：从源码构建
```bash
git clone https://github.com/RainDayDream/MeetingCopilot.git
cd MeetingCopilot
./create-signing-cert.sh   # 可选但推荐：创建本机固定签名证书，避免每次构建都要重新授权
./build.sh
open build/MeetingCopilot.app
```
> 重新构建后，必须先完全退出正在运行的 MeetingCopilot（⌘Q）再打开新构建，否则运行的仍是旧版本。

## 首次使用
1. **配置模型**：右上角齿轮 › 模型 API。选接口类型，填 Base URL、模型名、API Key（本机 Ollama 可不填）。截图解读需要支持图片输入的模型（例如 GPT-4o、Claude；DeepSeek 等纯文本模型会自动退回仅用转写）。关闭设置窗口时 API Key 写入系统钥匙串。
2. **授权**：点「开始监听」，在 系统设置 › 隐私与安全性 中允许「屏幕与系统音频录制」和「麦克风」。授权后**完全退出并重新打开**一次。
3. **下载识别模型**：首次监听会联网下载 Whisper 模型（默认 small，约 460MB）并优化，需要 1–2 分钟，状态栏显示进度，之后离线可用。可在 设置 › 通用 换模型（tiny/base 更快，large-v3 turbo 最准但更吃资源）。
   - 如改用云端识别：在 设置 › 通用 › 语音识别服务 选「阿里云百炼 Paraformer」，填入百炼 API Key；不需要下载本地模型，音频会发送到阿里云。

## 日常使用（完整说明见 [MANUAL.md](MANUAL.md)）
1. 开会前点相机图标，确认将被截取的屏幕；多显示器可在 设置 › 通用 固定选屏。
2. 选好右上角**预设**，点「开始监听」。左侧实时显示转写（橙=对方，蓝=我）。
3. 需要答案时点「立即回答」（⌘↩，或全局快捷键，默认 ⌃⌥A，可在设置里改）；底部输入框可补充具体问题（支持多行，回车换行，⌘↩ 发送）。
4. 工具栏「语言」默认自动；固定为中文或 English 识别更稳。
5. 会后切到「会后总结」预设；用导出按钮保存转写。
6. 左侧历史栏可以打开以前的对话、右键重命名；点「新话题」保存当前对话并开始新记录。
7. 右上角箭头按钮：复制提示词并打开你配置的网页（如 claude.ai），由你手动粘贴，本工具不会操控其他 App。

## 数据存放位置
App 开启了沙盒，数据都在 `~/Library/Containers/com.meetingcopilot.MeetingCopilot/Data/`：
- 识别模型：`Library/Application Support/MeetingCopilot/models/`
- 设置与预设：`Library/Application Support/MeetingCopilot/settings.json`（不含 API Key）
- 历史记录：`Library/Application Support/MeetingCopilot/history/`（本机 JSON；可在设置关闭保存或左侧清空）
- API Key：系统钥匙串，条目名 `com.meetingcopilot.MeetingCopilot`（模型 API 与云端语音识别各一条）
- 音频和截图不保存；历史只保存定稿转写和回答文本，不保存截图。

## 安全设计
- **只读**：不申请辅助功能权限，不模拟键鼠，不写入或控制其他 App；仅用 ScreenCaptureKit 读取音频与截图。
- **App Sandbox**：只能联网、用麦克风、读写你在保存面板里选定的文件。
- **云端语音识别是可选项**：开启后音频会发送给阿里云百炼；默认本地 Whisper，音频不出本机。云端 API Key 只存系统钥匙串。
- **历史记录只存在本机**：不自动上传；可在 设置 › 通用 关闭保存，或在左侧历史栏删除/清空。
- API 地址强制 https（本机 localhost 除外）。
- 转写和截图作为「资料」送入模型，系统提示词要求忽略其中的指令；模型输出只显示，不会被执行。
- 本 App 的截图始终排除自身窗口。
- 窗口默认不置顶，也不对截屏隐藏（均可在设置中开启）。

## 注意与限制
- 使用云端 API 时，转写文本和截图会发送给对应服务商；敏感场景请用本机 Ollama。
- 云端语音识别会把音频发送给阿里云百炼，按量计费；按段识别，延迟取决于网络，不显示本地模式那样的实时临时文字。
- 历史记录包含会议/面试原文，保存在本机且可能被同一台 Mac 的其他程序读取；敏感内容请关闭保存或及时清空。
- 录音或转写他人发言前，请遵守当地法律和对方意愿（面试、导师交流请先告知）。
- 语音识别：一次一句，句内中英混杂时英文术语偶有拼写偏差；多个远端说话人不区分，统一标为「对方」。
- 外放时麦克风会收到对方声音，可能重复出现为「我」，建议戴耳机或在设置中关闭麦克风转写。
- 已用合成语音验证本地识别（中文、英文、中英混合）与两种 API 的流式调用；真实会议软件中的长时间表现请自行实测并反馈。

## 常见问题
- **权限一直弹出 / 授权后无效**：多因签名身份变化。运行 `./create-signing-cert.sh` 后用 `./build.sh` 构建，在 系统设置 › 隐私与安全性 › 屏幕与系统音频录制 中删除旧条目并重新授权，然后完全退出再打开。
- **钥匙串反复要密码**：到「钥匙串访问」删除条目 `com.meetingcopilot.MeetingCopilot`，重新填一次 API Key，弹窗时选「始终允许」。
- **没有转写出文字**：看工具栏「对方」音量条，在动说明音频已捕获；首次使用需等模型下载加载完成。
